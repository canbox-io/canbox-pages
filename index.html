Canbox

轻量级应用运行时平台

基于 Electron 的三层架构应用平台：canbox-core 提供运行时服务，canbox-manager 管理应用，canbox-developer 辅助开发。
支持 Linux、Windows、macOS

立即下载 开始开发

功能特性

📦

应用管理

支持 APP 的导入、删除、启动和清理数据，按 appId 物理隔离，干净利落

🌐

创建网页应用

将任意网址封装为桌面应用，自动抓取 PWA manifest 预填信息，Chrome UA 伪装，菜单栏可定制，独立 userData 隔离

📚

仓库管理

添加 GitHub 仓库源，浏览和安装社区贡献的应用

🔌

核心服务

canbox-core 通过 -r 注入提供 store/db/dialog 等 29 个 IPC 通道，黑盒式数据隔离

🛠️

开发工具

canbox-developer 提供 APP 调试启动、打包发布等开发便利

🔄

自动更新

基于 GitHub Releases 的自动更新，启动后自动检查，也支持手动触发

🎨

个性化配置

可配置语言、字体、日志保留，支持窗口缩放（0.5x ~ 2.0x）

📁

文件任务管理

统一导入等文件操作的任务管理与进度跟踪

💻

多平台支持

基于 Electron，支持 Linux、Windows、macOS
