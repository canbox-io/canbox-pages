APP 中心

发现和安装基于 Canbox 开发的应用

  1. 开发你的应用

    基于 Canbox 框架开发你的 Electron 应用，确保项目包含 package.json（含 name、version、main、author、description 字段）。

  2. 添加 .canbox-app 文件

    在仓库根目录创建 .canbox-app 文件（JSON 格式），声明应用类型和元数据：

    {
  "type": "native",
  "electron": {
    "range": "^42.5.1"
  },
  "category": "development",
  "tags": ["json", "formatter"],
  "description": "JSON 格式化工具",
  "description_en": "JSON formatter",
  "logo": "logo.png"
}
  3. 添加 canbox-app Topic

    在 GitHub 仓库的 Settings → Topics 中添加 canbox-app 标签。系统会自动发现你的应用，无需提交 PR。

注意事项

  • 添加 topic 后最多 2 小时内即可在 APP 中心看到
  • .canbox-app 文件中的 type 字段必填，支持 native / web / pwa
  • native 类型应用需填写 electron.range 字段
  • logo 文件路径相对于仓库根目录，默认取 logo.png
  • category 可选值：development / network / utilities / productivity / graphics 等
